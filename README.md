# Companions — original creature RPG

An original, mobile-first creature-collecting RPG in development. This repository is separate from Pokémon Chaos.

## Prototype v0.1
- Choose Lumi (adaptable), Bront (defensive), or Skaryx (fast attacker).
- Fight turn-based encounters with four moves per starter, accuracy, damage, speed order, and HP.
- Track wins locally on the current device.
- Responsive, touch-friendly interface.

The current emoji are explicitly temporary placeholders, not approved creature art. The combat formulas and statistics are provisional and will be balanced through playtesting.

## Roadmap
1. Original creature sprites and animations.
2. Exploration map, wild encounters, and companion collection.
3. Trainable attributes: Power, Durability, Agility, Focus, Energy.
4. Branching three-phase transformations and smaller visible adaptations.
5. Cosmetic color variants, party management, narrative, and save upgrades.

## Deployment
The included GitHub Actions workflow publishes the static site to GitHub Pages when GitHub Pages is configured to use **GitHub Actions** as its source. Deployment may require repository settings authorization. No API keys, server, or paid hosting are required for this prototype.
